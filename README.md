## Projects Overview

### 1. Enterprise Business Intelligence Suite for a Multi-Region Company (DA-01)

**Project Domain:** Business Intelligence and Data Analytics

**Objective:**

To develop an integrated Business Intelligence solution that provides insights into business performance across multiple regions through data analysis, structured data modeling, and interactive reporting.

**Project Description:**

This project uses the Microsoft AdventureWorks sample database to analyze business data and develop an interactive Power BI reporting solution.

The project focuses on SQL-based data analysis, data preparation, data modeling, DAX calculations, and business performance visualization.

**Key Components:**

- AdventureWorks database analysis
- SQL Server database management
- SQL queries and data validation
- Data modeling and transformation
- Power BI dashboard development
- DAX measures and KPI calculations
- Sales and regional performance analysis
- Product performance analysis
- Documentation and testing

**Technologies Used:**

- Microsoft SQL Server
- SQL
- Power BI
- DAX
- Power Query

**Repository Folder:** `DA-01_Enterprise_BI_Suite/`

---

### 2. Customer 360 and Marketing Attribution Platform (DA-02)

**Project Domain:** Customer Analytics and Marketing Analytics

**Objective:**

To develop a unified customer analytics solution that combines website activity, CRM information, and marketing data to understand customer behavior and evaluate marketing channel performance.

**Project Description:**

This project uses Google BigQuery and GA4 sample e-commerce data, together with synthetic CRM and marketing datasets.

It focuses on customer data integration, identity resolution, customer segmentation, marketing attribution, and campaign performance analysis.

**Key Components:**

- GA4 e-commerce data analysis
- CRM customer data integration
- Customer identity resolution
- BigQuery SQL analysis
- Customer segmentation and RFM analysis
- Customer Lifetime Value analysis
- Marketing attribution analysis
- First-touch and last-touch attribution
- Linear and time-decay attribution
- Campaign performance and ROI analysis
- Dashboard development
- Documentation and validation

**Technologies Used:**

- Google BigQuery
- SQL
- Python
- dbt
- Google Analytics 4 (GA4)
- Segment
- Power BI

**Repository Folder:** `DA-02_Customer_360_Marketing_Attribution/`
